HALL OF FAMOUS FAILURES

These are not anecdotes. These are theorems that were never proved. Every entry below is a mathematical property that existed, was never verified, and caused measurable human and financial catastrophe.

1985 – 1987
Therac-25 Radiation Overdose
Race Condition · Concurrent State Machine
A race condition in the radiation therapy control software allowed lethal radiation doses when operators typed commands quickly. Removed hardware interlocks depended on unverified software correctness.
Human Toll
6 DEATHS · 3 SERIOUS INJURIES
✓ AXIOM DETECTION: Race condition found at BMC k=3, taint analysis flags unguarded shared state in operator mode transitions
1996
Ariane 5 Flight 501
Integer Overflow · Type Safety Violation
A 64-bit floating point value representing horizontal velocity was converted to a 16-bit integer. The value was valid for Ariane 4 but exceeded the representable range in the new flight profile, causing the inertial reference system to crash.
Financial Toll
$370M SATELLITE LOST · 40 SECONDS OF FLIGHT
✓ AXIOM DETECTION: Type checker + SMT arithmetic constraint: ∀v ∈ velH: fits_int16(v) → REFUTED with counterexample v=32768.0
2012
Knight Capital Meltdown
Dead Code Resurrection · Incomplete Deployment
A partial software deployment reactivated an obsolete trading function ("Power Peg") that had been dead code for years. The function ran at full production scale for 45 minutes before manual shutdown was possible.
Financial Toll
$440M IN 45 MINUTES · COMPANY DESTROYED
✓ AXIOM DETECTION: Reachability analysis flags dead function as reachable post-deployment; invariant: ¬active(PowerPeg) → REFUTED on new server image
2018 – 2019
Boeing 737 MAX MCAS
Specification Error · Single Sensor Design
The MCAS flight control system was designed to activate on input from a single angle-of-attack sensor without adequate failure mode specifications. The system's behavior under sensor malfunction was never formally specified or verified against flight envelope invariants.
Human Toll
346 DEATHS · $20B+ LIABILITY
⚡ PARTIAL: SpecAgent flags missing failure mode spec; RiskAgent: risk=0.98 → EXTREME VERIFY + Human Gate required
2014
Heartbleed (OpenSSL)
Buffer Over-Read · Missing Bounds Check
The TLS heartbeat extension read up to 64KB of server memory beyond the buffer boundary by trusting user-supplied length parameters without validation. A trivial missing bounds check exposed private keys, passwords, and session tokens for over two years.
Security Toll
MILLIONS OF SERVERS EXPOSED · CVE-2014-0160
✓ AXIOM DETECTION: Taint analysis + BMC: ∀len: len ≤ payload_len → REFUTED; counterexample: len=65535, payload_len=1
1999
Mars Climate Orbiter
Unit Mismatch · Interface Contract Violation
Navigation software from one contractor produced thruster impulse data in pound-force·seconds. The receiving system expected newton·seconds. No interface contract specified units. The spacecraft entered the Martian atmosphere at the wrong angle and was destroyed.
Financial Toll
$327M SPACECRAFT LOST
✓ AXIOM DETECTION: Interface Validator enforces dimensional types; SMT constraint: units(thruster_input) = N·s → REFUTED; got lbf·s
1991
Patriot Missile Failure
Floating-Point Accumulation · Timing Error
System clock time was stored as a 24-bit fixed-point number. After 100 hours of continuous operation, accumulated floating-point truncation error was 0.34 seconds, causing the tracking gate to miss an incoming Scud missile.
Human Toll
28 SOLDIERS KILLED · DHAHRAN, SAUDI ARABIA
✓ AXIOM DETECTION: Abstraction engine over-approximates fixed-point arithmetic error; BMC shows gate_miss at t=360000s with ε accumulation
1994
Intel Pentium FDIV Bug
Lookup Table Error · Arithmetic Property Violation
Five entries were missing from the SRT division algorithm's lookup table due to a flaw in the constant generation script. Caused rare but reproducible division errors affecting high-precision scientific and financial computation.
Financial Toll
$475M RECALL · 1M+ PROCESSORS
✓ AXIOM DETECTION: SMT arithmetic: ∀a,b: fdiv(a,b) = a/b → REFUTED with explicit 5 counterexample cases in SRT quotient table
2024
CrowdStrike Falcon Update
Null Pointer Dereference · Channel File 291
A rapid content configuration update (Channel File 291) contained a null pointer that the sensor driver dereferenced without validation during an out-of-bounds memory read, causing an uncatchable kernel panic across 8.5 million Windows systems globally.
Economic Toll
8.5M SYSTEMS DOWN · $5.4B+ ESTIMATED LOSSES
✓ AXIOM DETECTION: Taint analysis: deref(ptr) where ptr ∈ Tainted(user_config) → REFUTED; null deref at channel_file offset 0x1A3
